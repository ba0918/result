# inspect() / inspectErr() メソッド実装計画

**作成日時**: 2025-07-12 19:41:55  
**対象機能**: Result型への inspect() / inspectErr() メソッド追加  
**目的**: デバッグ用途での副作用実行機能を提供

## 1. ユーザ要求の理解

### 機能要件
- デバッグ用途で値やエラーを検査する機能
- 値を変更せずに副作用（ログ出力等）を実行
- メソッドチェーンを中断しない設計
- Rust標準のinspect()機能に準拠

### 非機能要件
- 既存コードへの影響なし
- パフォーマンスへの最小限の影響
- 型安全性の維持

## 2. 関連コード分析結果

## 3. 実装方針決定

### 3.1 メソッドシグネチャ設計
```php
// Resultインターフェースに追加
/**
 * 成功値を検査し、副作用を実行する（値は変更しない）
 * @param callable(T): void $fn
 * @return Result<T, E>
 */
public function inspect(callable $fn): Result;

/**
 * エラー値を検査し、副作用を実行する（エラーは変更しない）
 * @param callable(E): void $fn  
 * @return Result<T, E>
 */
public function inspectErr(callable $fn): Result;
```

### 3.2 実装戦略
- **Ok::inspect()**: 関数実行 + 自身を返す
- **Ok::inspectErr()**: 何もせず自身を返す
- **Err::inspect()**: 何もせず自身を返す  
- **Err::inspectErr()**: 関数実行 + 自身を返す

### 3.3 Rust準拠性
```rust
// Rust標準の動作をPHPで再現
impl<T, E> Result<T, E> {
    fn inspect<F>(self, f: F) -> Self where F: FnOnce(&T) {
        if let Ok(ref t) = self { f(t); }
        self
    }
    fn inspect_err<F>(self, f: F) -> Self where F: FnOnce(&E) {
        if let Err(ref e) = self { f(e); }
        self
    }
}
```
