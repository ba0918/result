# ショートハンドメソッド群実装計画書

## 実装日時
2025年7月13日 13:21:04

## 概要
RustのResult型とOption型互換のショートハンドメソッド群を実装し、コードの簡潔性と利便性を大幅向上させる。

## 要件分析

### 実装対象メソッド
1. **isOkAnd() / isErrAnd() (Result型)**
   - 成功/失敗判定と条件チェックを同時実行
   - `result.isOk() && predicate(value)` の短縮形
   
2. **isSomeAnd() (Option型)**
   - 値の存在判定と条件チェックを同時実行
   - `option.isSome() && predicate(value)` の短縮形
   - Rustのis_some_and()と完全互換

3. **mapOr() / mapOrElse() (Result型)**
   - 成功時変換+失敗時デフォルト値を1つのメソッドで実現
   - チェーン処理の効率化
   - **注意**: Option型には既に実装済み

### 現在の実装状況
- Result型: `isOk()`, `isErr()`, `map()`, `mapErr()` 実装済み
- Option型: `isSome()`, `isNone()`, `mapOr()`, `mapOrElse()` 実装済み

## 技術仕様

### メソッドシグネチャ

#### Result型新規メソッド

```php
// Result interface
/**
 * 成功時のみ述語関数を実行し、その結果を返す
 * @param callable(T): bool $predicate
 * @return bool
 */
public function isOkAnd(callable $predicate): bool;

/**
 * 失敗時のみ述語関数を実行し、その結果を返す
 * @param callable(E): bool $predicate
 * @return bool
 */
public function isErrAnd(callable $predicate): bool;

/**
 * 成功時は値を変換し、失敗時はデフォルト値を返す
 * @template U
 * @param callable(T): U $fn
 * @param U $default
 * @return U
 */
public function mapOr(callable $fn, mixed $default): mixed;

/**
 * 成功時は値を変換し、失敗時はクロージャの結果を返す
 * @template U
 * @param callable(T): U $fn
 * @param callable(E): U $defaultFn
 * @return U
 */
public function mapOrElse(callable $fn, callable $defaultFn): mixed;
```

#### Option型新規メソッド

```php
// Option interface
/**
 * 値を持ち、かつ述語関数を満たす場合のみtrueを返す
 * @param callable(T): bool $predicate
 * @return bool
 */
public function isSomeAnd(callable $predicate): bool;
```

### 実装パターン

#### Ok クラス実装例

```php
public function isOkAnd(callable $predicate): bool
{
    return $predicate($this->value);
}

public function isErrAnd(callable $predicate): bool
{
    return false;
}

public function mapOr(callable $fn, mixed $default): mixed
{
    return $fn($this->value);
}

public function mapOrElse(callable $fn, callable $defaultFn): mixed
{
    return $fn($this->value);
}
```

#### Err クラス実装例

```php
public function isOkAnd(callable $predicate): bool
{
    return false;
}

public function isErrAnd(callable $predicate): bool
{
    return $predicate($this->error);
}

public function mapOr(callable $fn, mixed $default): mixed
{
    return $default;
}

public function mapOrElse(callable $fn, callable $defaultFn): mixed
{
    return $defaultFn($this->error);
}
```

#### Some クラス実装例

```php
public function isSomeAnd(callable $predicate): bool
{
    return $predicate($this->value);
}
```

#### None クラス実装例

```php
public function isSomeAnd(callable $predicate): bool
{
    return false;
}
```

## テスト戦略

### 1. 単体テスト（必須）

### 2. テストケース設計

#### isOkAnd/isErrAnd テストケース
- ✅ Ok値で述語true → true
- ✅ Ok値で述語false → false
- ✅ Err値で述語true/false → false (isOkAndの場合)
- ✅ Err値で述語true → true (isErrAndの場合)
- ✅ Err値で述語false → false (isErrAndの場合)
- ✅ Ok値で述語true/false → false (isErrAndの場合)

#### mapOr/mapOrElse テストケース
- ✅ Ok値で変換関数適用
- ✅ Err値でデフォルト値返却
- ✅ Err値でデフォルト関数実行（遅延評価）
- ✅ 型安全性確認

#### isSomeAnd テストケース
- ✅ Some値で述語true → true
- ✅ Some値で述語false → false
- ✅ None値で述語true/false → false
