# contains() / contains_err() 実装計画書

## 概要

PHP Result型ライブラリに`contains()`と`contains_err()`メソッドを追加する実装計画。RustのResult型にはこれらのメソッドは存在しないが、値の存在確認機能として有用性が高いため独自実装する。

## 要件分析

### 機能要件
- `contains(mixed $value): bool` - Ok値が指定値と等価かを確認
- `contains_err(mixed $error): bool` - Err値が指定エラーと等価かを確認
- 厳密比較（`===`）による値の比較
- 既存の設計パターンとの一貫性維持

### 非機能要件
- 型安全性の確保（PHPDoc Generics）
- Immutableな設計の継承
- パフォーマンスオーバーヘッドの最小化
- 下位互換性の保持

## 技術仕様

### メソッドシグネチャ

```php
interface Result
{
    /**
     * Ok値が指定された値を含むかどうかを確認する
     *
     * @param mixed $value 確認したい値
     * @return bool Ok値が指定値と厳密に等価な場合true、それ以外はfalse
     */
    public function contains(mixed $value): bool;

    /**
     * Err値が指定されたエラーを含むかどうかを確認する
     *
     * @param mixed $error 確認したいエラー値
     * @return bool Err値が指定エラーと厳密に等価な場合true、それ以外はfalse
     */
    public function containsErr(mixed $error): bool;
}
```

### 実装ロジック

#### Ok<T>クラス
```php
public function contains(mixed $value): bool
{
    return $this->value === $value;
}

public function containsErr(mixed $error): bool
{
    return false; // Okは常にエラーを含まない
}
```

#### Err<E>クラス
```php
public function contains(mixed $value): bool
{
    return false; // Errは常に値を含まない
}

public function containsErr(mixed $error): bool
{
    return $this->error === $error;
}
```

## テスト戦略

### 基本テストケース
1. **Ok値での`contains()`テスト**
   - 等価な値での確認（true）
   - 非等価な値での確認（false）
   - 型が異なる値での確認（false）

2. **Err値での`containsErr()`テスト**
   - 等価なエラーでの確認（true）
   - 非等価なエラーでの確認（false）
   - 型が異なるエラーでの確認（false）

3. **交差テスト**
   - Ok値での`containsErr()`（常にfalse）
   - Err値での`contains()`（常にfalse）

### エッジケーステスト
1. **null値の比較**
   ```php
   $ok = new Ok(null);
   assertTrue($ok->contains(null));
   assertFalse($ok->contains(0));
   ```

2. **オブジェクト参照比較**
   ```php
   $obj = new stdClass();
   $ok = new Ok($obj);
   assertTrue($ok->contains($obj));
   assertFalse($ok->contains(new stdClass()));
   ```

3. **配列の厳密比較**
   ```php
   $array = [1, 2, 3];
   $ok = new Ok($array);
   assertTrue($ok->contains([1, 2, 3]));
   assertFalse($ok->contains(['1', '2', '3']));
   ```

4. **数値型の厳密比較**
   ```php
   $ok = new Ok(42);
   assertTrue($ok->contains(42));
   assertFalse($ok->contains('42'));
   assertFalse($ok->contains(42.0));
   ```
