# Option型flatten()メソッド実装計画

## 概要
Option型にflatten()メソッドを実装し、ネストしたOption<Option<T>>をOption<T>に平坦化する機能を追加する。

## 背景・目的
- Rust互換のOption型APIの完全性向上
- ネストしたOptionの簡潔な処理を可能にする
- Result型flatten()の成功を踏まえた一貫性のある実装

## 技術仕様

### 機能要件
- **型シグネチャ**: `Option<Option<T>>` → `Option<T>`
- **動作**: ネストしたOptionの一段階平坦化
- **Rust互換**: 完全なRust標準ライブラリ準拠

### 実装パターン
1. **Some(Some(value))** → `Some(value)`
2. **Some(None)** → `None`
3. **Some(non-Option)** → `Some(non-Option)` (自身を返す)
4. **None** → `None` (自身を返す)

### PHPStan対応
- 戻り値型: `Option<mixed>` (型安全性確保)
- `instanceof Option`による実行時型チェック
- mixed型の適切な処理

## テスト戦略

### 基本動作テスト
```php
// Some(Some(value)) → Some(value)
$nested = Some::of(Some::of(42));
assertEquals(Some::of(42), $nested->flatten());

// Some(None) → None
$someNone = Some::of(None::instance());
assertEquals(None::instance(), $someNone->flatten());

// None → None
assertEquals(None::instance(), None::instance()->flatten());
```

### エッジケーステスト
```php
// 深いネスト: Some(Some(Some(value)))
$deepNested = Some::of(Some::of(Some::of(42)));
assertEquals(Some::of(Some::of(42)), $deepNested->flatten());

// 非Option値: Some(non_option_value)
$nonOption = Some::of("string_value");
assertEquals($nonOption, $nonOption->flatten());

// null値処理
$someNull = Some::of(null);
assertEquals($someNull, $someNull->flatten());
```
