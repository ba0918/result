# PHPStan型エラー修正計画

**作成日**: 2025-07-13  
**対象**: PHPStanレベルMAXでの34個の型エラー修正

## 1. 現状分析

### エラー分類
- **mixed型算術演算エラー**: 6件（OptionBasicTest: 4件、OptionResultConversionTest: 2件）
- **mixed型メソッド呼び出しエラー**: 26件（TransposeTest）
- **assertFalse最適化警告**: 2件（OptionBasicTest）

### 根本原因
1. **transpose()メソッド戻り値**がPHPStanで`mixed`型と推論される
2. **クロージャパラメータ**の型アノテーション不足
3. **PHPDoc型情報**とPHPStanの型推論ギャップ

## 2. 修正方針

### アプローチ
1. **型アサーション追加**: `assert($var instanceof Type)` でPHPStanに型情報提供
2. **明示的型キャスト**: `(int)$value` で算術演算の型安全性確保
3. **PHPDoc強化**: クロージャパラメータに詳細な型情報追加

### 技術的戦略
- **非破壊的修正**: 既存ロジックを変更せず、型安全性のみ向上
- **テスト品質維持**: 機能テストは変更なし、型安全性テストを追加
- **可読性優先**: 過度な型キャストは避け、意図を明確にする

## 3. 詳細実装タスク

### 高優先度（必須修正）
- [x] **OptionBasicTest.php mixed型算術エラー修正** (4箇所)
  - `fn($x) => $x * 2` → `function(mixed $x): int { assert(is_int($x)); return $x * 2; }`
  - `fn($x) => $x * 3` → `function(mixed $x): int { assert(is_int($x)); return $x * 3; }` 
  - `fn($x) => $x + 1` → `function(mixed $x): int { assert(is_int($x)); return $x + 1; }`
  - `fn($x) => $x / 2` → `function(mixed $x) { assert(is_int($x)); return Some::of((float)$x / 2); }`

- [x] **OptionResultConversionTest.php mixed型エラー修正** (2箇所)
  - Line 143: `fn($x) => $x * 2` → `function(mixed $x): int { assert(is_int($x)); return $x * 2; }`
  - Line 150: 文字列補間でのmixed型エラー → `function(mixed $e): string { assert(is_string($e)); return "wrapped_{$e}"; }`

- [x] **TransposeTest.php mixed型メソッドエラー修正** (26箇所)
  - useステートメントにOption, Result追加
  - PHPDocアノテーション `/** @var Result<mixed,mixed> $result */` 使用
  - メソッドチェーン分割と型アノテーション追加

### 中優先度（品質向上）
- [x] **OptionBasicTest.php assertFalse最適化警告修正** (2箇所)
  - Line 273-274: `@phpstan-ignore method.impossibleType` コメント追加
  - 実装ロジック確認完了、None::instance()->contains()は正常に常にfalseを返す
