# Result型 or()/orElse() メソッド実装計画

**作成日時**: 2025-07-12 20:27:57  
**プロジェクト**: PHP Result型ライブラリ  
**実装対象**: or() / orElse() メソッド

## 1. 実装要件分析

### 1.1 ユーザ要求
- Result型ライブラリにor()/orElse()機能を追加
- RustのResult型のor/or_elseメソッドと同等の機能を提供
- 既存の実装との一貫性を保持

### 1.2 機能要件
#### or() メソッド
- **目的**: Errの場合に代替のResultを返す（即座に評価）
- **動作**: 
  - Ok値の場合：自身を返す
  - Err値の場合：引数のResultを返す
- **引数**: `Result $res`
- **戻り値**: `Result`

#### orElse() メソッド
- **目的**: Errの場合に代替のResultを返す（遅延評価）
- **動作**:
  - Ok値の場合：自身を返す
  - Err値の場合：エラー値を引数として関数を実行し、その結果を返す
- **引数**: `callable(E): Result $fn`
- **戻り値**: `Result`

### 1.3 既存機能との違い分析

| 機能 | unwrapOr | unwrapOrElse | or | orElse |
|------|----------|--------------|-----|--------|
| 戻り値 | 値（T） | 値（T） | Result | Result |
| 即座評価 | ○ | × | ○ | × |
| エラー処理 | デフォルト値 | 関数呼び出し | 代替Result | 関数でResult生成 |
| 用途 | 値の取得 | 値の取得 | Resultチェーン | Resultチェーン |

## 2. Rust仕様との対比

### 2.1 Rust or()の仕様
```rust
pub fn or<F>(self, res: Result<T, F>) -> Result<T, F>
```
- Errの場合に引数のResultを返す
- 即座に評価される
- 型パラメータFが新しいエラー型

### 2.2 Rust or_else()の仕様
```rust
pub fn or_else<F, O>(self, op: O) -> Result<T, F>
where O: FnOnce(E) -> Result<T, F>
```
- Errの場合にエラー値を引数として関数を実行
- 遅延評価
- 新しいエラー型を返せる

### 2.3 PHP実装での適応
- PHPの型システム制約により、Genericsは注釈のみ
- `mixed`型を使用した柔軟な実装
- 実行時型チェックは最小限

## 3. 実装方針

### 3.1 設計原則
1. **一貫性**: 既存のメソッドと同じパターンで実装
2. **不変性**: immutableな設計を維持
3. **型安全性**: PHPDocでGenericsを表現
4. **継承禁止**: finalクラスを維持

### 3.2 メソッドシグネチャ（PHP）

#### Resultインターフェース
```php
/**
 * Errの場合に代替のResultを返す（即座評価）
 *
 * @template F
 * @param Result<T, F> $res
 * @return Result<T, F>
 */
public function or(Result $res): Result;

/**
 * Errの場合に代替のResultを返す（遅延評価）
 *
 * @template F
 * @param callable(E): Result<T, F> $fn
 * @return Result<T, F>
 */
public function orElse(callable $fn): Result;
```

#### Okクラス実装
```php
public function or(Result $res): Result
{
    return $this; // 常に自身を返す
}

public function orElse(callable $fn): Result
{
    return $this; // 常に自身を返す（関数は実行しない）
}
```

#### Errクラス実装
```php
public function or(Result $res): Result
{
    return $res; // 引数のResultを返す
}

public function orElse(callable $fn): Result
{
    return $fn($this->error); // エラー値で関数を実行
}
```
