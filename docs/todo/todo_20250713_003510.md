# flatten()メソッド実装計画

作成日時: 2025-07-13 00:35:10

## 概要

RustのResult型のflatten()メソッドをPHPで実装する。ネストしたResult型（`Result<Result<T, E>, E>`）を一段階平坦化して`Result<T, E>`に変換する機能を提供する。

## 調査結果

### Rustでのflatten()仕様

**機能:** ネストしたResultを一段階平坦化
**シグネチャ:** `impl<T, E> Result<Result<T, E>, E> { pub fn flatten(self) -> Result<T, E>; }`
**現状:** Rustでは`#![feature(result_flattening)]`フィーチャーゲートの下で実装中（未安定化）

**動作パターン:**
- `Ok(Ok(value))` → `Ok(value)`
- `Ok(Err(error))` → `Err(error)`
- `Err(error)` → `Err(error)`

- `isOk()` / `isErr()` - 状態判定

## 実装方針

### 1. 設計決定

**基本動作:**
- `Result<Result<T, E>, E>` → `Result<T, E>` の変換
- 一段階のみの平坦化（多重ネストは段階的に処理）
- 非Resultの値に対しては何もせずそのまま返す

**PHP実装での考慮事項:**
- 型システムの制約により、実行時型チェックでResultインスタンスを確認
- PHPDocでGenericsを表現
- エラーハンドリングは既存のパターンに従う

### 2. インターフェース設計

```php
/**
 * ネストしたResultを一段階平坦化する
 *
 * @return Result<T, E>
 */
public function flatten(): Result;
```

### 3. 実装戦略

**Okクラス:**
1. 内部値がResultインスタンスかチェック
2. Resultなら内部Resultをそのまま返す
3. 非Resultなら自身をそのまま返す

**Errクラス:**
- 自身をそのまま返す（何もしない）

## テスト戦略

### 基本動作テスト

```php
// Ok(Ok(value)) → Ok(value)
$nested = new Ok(new Ok(42));
$flattened = $nested->flatten();
$this->assertInstanceOf(Ok::class, $flattened);
$this->assertEquals(42, $flattened->unwrap());

// Ok(Err(error)) → Err(error)
$nested = new Ok(new Err("error"));
$flattened = $nested->flatten();
$this->assertInstanceOf(Err::class, $flattened);
$this->assertEquals("error", $flattened->unwrapErr());

// Err(error) → Err(error)
$err = new Err("original error");
$flattened = $err->flatten();
$this->assertSame($err, $flattened);

// Ok(non_result) → Ok(non_result)
$simple = new Ok("simple value");
$flattened = $simple->flatten();
$this->assertSame($simple, $flattened);
```

### エッジケーステスト

**多重ネスト:**
```php
// 一段階のみ平坦化されることを確認
$tripleNested = new Ok(new Ok(new Ok(42)));
$flattened = $tripleNested->flatten();
$this->assertInstanceOf(Ok::class, $flattened);
$this->assertInstanceOf(Ok::class, $flattened->unwrap());
```
