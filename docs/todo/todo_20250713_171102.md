# 新機能実装計画書

**作成日時**: 2025-07-13 17:11:02  
**実装対象**: Result型/Option型の高度メソッド追加

## 要求概要

前回のレビューで提案された以下4つの機能を実装する：

### 型変換メソッド
1. **ok() / err() (Result型)**
   - Result → Option変換
   - エラーハンドリングパターンの多様化

2. **expectErr() (Result型)**
   - エラー値のカスタムメッセージ付き取り出し
   - デバッグ体験の向上

### 高度な結合操作
3. **xor() (Option型)**
   - 排他的OR操作
   - 条件分岐ロジックの簡潔化

4. **zip() (Option型)**
   - 2つのOptionの結合
   - 複数値の同期処理

## コードベース分析結果

### 現在の実装状況
- **Result型**: インターフェース + Ok/Err実装クラス
- **Option型**: インターフェース + Some/None実装クラス
- **既存メソッド**: contains(), flatten(), transpose()等が実装済み
- **テスト体制**: PHPUnit完備、PHPStanレベルMAXで型安全性確保

### アーキテクチャ特徴
- 全クラスは`final`で継承不可
- プロパティは`readonly`でimmutable
- PHPDoc Genericsで型安全性確保
- シングルトンパターン（None）の採用

## Rust仕様調査結果

### Result::ok() / Result::err()
```rust
// ok(): Result<T, E> → Option<T>
Ok(2).ok() => Some(2)
Err("error").ok() => None

// err(): Result<T, E> → Option<E>
Ok(2).err() => None
Err("error").err() => Some("error")
```

### Result::expect_err()
```rust
// Errの場合にエラー値を返し、Okの場合にパニック
Err("error").expect_err("should be error") => "error"
Ok(2).expect_err("should be error") => panic!
```

### Option::xor()
```rust
// 排他的OR: 片方のみSomeの場合にSome、両方Some/両方Noneの場合にNone
Some(2).xor(None) => Some(2)
None.xor(Some(2)) => Some(2)
Some(2).xor(Some(3)) => None
None.xor(None) => None
```

### Option::zip()
```rust
// 両方Someの場合にタプル、片方でもNoneの場合にNone
Some(1).zip(Some("hi")) => Some((1, "hi"))
Some(1).zip(None) => None
None.zip(Some("hi")) => None
```

## 実装設計

### 1. Result::ok() / Result::err()

**インターフェース追加**:
```php
// src/Result.php
public function ok(): Option;
public function err(): Option;
```

**Ok実装**:
```php
// src/Ok.php
public function ok(): Option {
    return Some::of($this->value);
}
public function err(): Option {
    return None::instance();
}
```

**Err実装**:
```php
// src/Err.php
public function ok(): Option {
    return None::instance();
}
public function err(): Option {
    return Some::of($this->error);
}
```

### 2. Result::expectErr()

**インターフェース追加**:
```php
// src/Result.php
/**
 * @return E
 * @throws UnwrapException
 */
public function expectErr(string $message): mixed;
```

**Ok実装**:
```php
// src/Ok.php
public function expectErr(string $message): mixed {
    throw new UnwrapException($message . ': ' . print_r($this->value, true));
}
```

**Err実装**:
```php
// src/Err.php
public function expectErr(string $message): mixed {
    return $this->error;
}
```

### 3. Option::xor()

**インターフェース追加**:
```php
// src/Option.php
/**
 * @template U
 * @param Option<U> $opt
 * @return Option<T|U>
 */
public function xor(Option $opt): Option;
```

**Some実装**:
```php
// src/Some.php
public function xor(Option $opt): Option {
    return $opt->isNone() ? $this : None::instance();
}
```

**None実装**:
```php
// src/None.php
public function xor(Option $opt): Option {
    return $opt;
}
```

### 4. Option::zip()

**インターフェース追加**:
```php
// src/Option.php
/**
 * @template U
 * @param Option<U> $opt
 * @return Option<array{T, U}>
 */
public function zip(Option $opt): Option;
```

**Some実装**:
```php
// src/Some.php
public function zip(Option $opt): Option {
    return $opt->isSome() ? Some::of([$this->value, $opt->unwrap()]) : None::instance();
}
```

**None実装**:
```php
// src/None.php
public function zip(Option $opt): Option {
    return $this;
}
```
