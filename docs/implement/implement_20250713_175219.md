## 実装パターンと動作仕様

### Result型 isOkAnd/isErrAnd
```php
// Ok値での条件付き判定
$result = Ok::of(42);
$result->isOkAnd(fn($x) => $x > 40); // true
$result->isErrAnd(fn($err) => true); // false

// Err値での条件付き判定  
$result = Err::of("not found");
$result->isOkAnd(fn($x) => true);             // false
$result->isErrAnd(fn($err) => str_contains($err, "not")); // true
```

### Result型 mapOr/mapOrElse
```php
// mapOr: デフォルト値付き変換
Ok::of(5)->mapOr(fn($x) => $x * 2, 0);   // 10
Err::of("error")->mapOr(fn($x) => $x * 2, 0); // 0

// mapOrElse: 遅延評価デフォルト値
Ok::of(10)->mapOrElse(fn($x) => $x / 2, fn($err) => -1);   // 5
Err::of("div0")->mapOrElse(fn($x) => $x / 2, fn($err) => -1); // -1
```

### Option型 isSomeAnd
```php
// Some値での条件付き判定
Some::of(42)->isSomeAnd(fn($x) => $x > 40); // true
Some::of(30)->isSomeAnd(fn($x) => $x > 40); // false
None::instance()->isSomeAnd(fn($x) => true); // false
```
