## 実装の技術詳細

### and()メソッドの動作仕様
1. **Ok + Ok**: 2番目のOkを返す
2. **Ok + Err**: Errを返す  
3. **Err + Ok**: 最初のErrを返す（2番目は無視）
4. **Err + Err**: 最初のErrを返す（2番目は無視）

### 型安全性
- PHPDocによるGenerics表現: `Result<U, E|F>`
- PHPStan最大レベルでエラーゼロ
- 異なる型のResult間での連携をサポート

### パフォーマンス特性
- 即座評価（`andThen()`とは異なり関数ではなく値を受け取る）
- 軽量な実装（新たなオブジェクト生成は最小限）
- メモリ効率的（readonly修飾子によるimmutability）
