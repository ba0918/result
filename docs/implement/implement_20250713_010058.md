## 実装機能詳細

### Option型基本機能
- `isSome()` / `isNone()` - 値の有無判定
- `unwrap()` / `unwrapOr()` / `unwrapOrElse()` / `expect()` - 値の取り出し
- `map()` / `mapOr()` / `mapOrElse()` - 値の変換
- `andThen()` - モナド的チェーン処理
- `filter()` - 条件による値のフィルタリング
- `inspect()` - デバッグ用副作用実行
- `or()` / `orElse()` / `and()` - Option間の結合操作
- `contains()` - 値の存在確認（厳密比較）

### Option-Result相互変換機能
- `Option::transpose()` - Option<Result<T,E>> → Result<Option<T>,E>
- `Result::transpose()` - Result<Option<T>,E> → Option<Result<T,E>>
- `Option::okOr()` - Option → Result（エラー指定）
- `Option::okOrElse()` - Option → Result（エラークロージャ）

### transpose()変換ルール

#### Option → Result
- `None` → `Ok(None)`
- `Some(Ok(value))` → `Ok(Some(value))`
- `Some(Err(error))` → `Err(error)`
- `Some(non-Result)` → `Ok(Some(value))`

#### Result → Option
- `Ok(None)` → `None`
- `Ok(Some(value))` → `Some(Ok(value))`
- `Err(error)` → `Some(Err(error))`
- `Ok(non-Option)` → `Some(Ok(value))`

### アーキテクチャ一貫性
- 既存のResult型と同様のパターンで実装
- `final` クラスによる継承禁止
- `readonly` プロパティによるimmutability
- PHPDocによるGenerics表現

### None実装のシングルトンパターン
```php
final class None implements Option
{
    private static ?self $instance = null;
    
    public static function instance(): self
    {
        if (self::$instance === null) {
            self::$instance = new self();
        }
        return self::$instance;
    }
}
```

## 使用例

### 基本的な使用法
```php
use Mizumi\Result\{Some, None, Ok, Err};

// Option型の基本使用
$some = Some::of(42);
$none = None::instance();

$result = $some->map(fn($x) => $x * 2)
              ->filter(fn($x) => $x > 50)
              ->unwrapOr(0); // 84

// transpose()による相互変換
$optionResult = Some::of(Ok::of('success'));
$resultOption = $optionResult->transpose(); // Ok(Some('success'))

// Option → Result変換
$result = $some->okOr('error'); // Ok(42)
$result = $none->okOr('error'); // Err('error')
```

### 実用的なユースケース
```php
// データベース検索 + バリデーション
$user = findUser($id)                    // Option<User>
    ->filter(fn($user) => $user->isActive())
    ->okOr('User not found or inactive') // Result<User, string>
    ->andThen(fn($user) => validateUser($user))
    ->map(fn($user) => $user->toArray());
```
