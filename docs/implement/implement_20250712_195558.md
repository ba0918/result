## 実装概要

RustのResult型に準拠したinspect()およびinspectErr()メソッドをPHP実装のResult型に追加しました。これらのメソッドはデバッグ用途で値やエラーを検査する機能を提供し、値を変更せずに副作用（ログ出力等）を実行できます。

## 使用例

### 基本的な使用法

```php
use Mizumi\Result\Ok;
use Mizumi\Result\Err;

// Ok値の検査
$result = new Ok(42);
$result->inspect(function($value) {
    echo "Success value: $value\n"; // 実行される
});

// Err値の検査
$result = new Err('error message');
$result->inspectErr(function($error) {
    error_log("Error occurred: $error"); // 実行される
});
```

### メソッドチェーンでの使用

```php
$result = new Ok(10)
    ->map(fn($x) => $x * 2)
    ->inspect(fn($value) => echo "Intermediate: $value\n") // "Intermediate: 20"
    ->map(fn($x) => $x + 5)
    ->inspect(fn($value) => echo "Final: $value\n");     // "Final: 25"
    
echo $result->unwrap(); // 25
```

### 実装パターン

#### Ok クラス
```php
public function inspect(callable $fn): Result
{
    $fn($this->value);  // 値に関数適用
    return $this;       // 自身を返却
}

public function inspectErr(callable $fn): Result
{
    return $this;       // 何もせず自身を返却
}
```

#### Err クラス
```php
public function inspect(callable $fn): Result
{
    return $this;       // 何もせず自身を返却
}

public function inspectErr(callable $fn): Result
{

}
```

### テスト戦略

副作用の確認にはフラグベースのテスト手法を採用:

```php
public function testInspectOnOkExecutesFunction(): void
{
    $sideEffectExecuted = false;
    $inspectedValue = null;
    
    $result = new Ok(42);
    $returnedResult = $result->inspect(function($value) use (&$sideEffectExecuted, &$inspectedValue) {
        $sideEffectExecuted = true;
        $inspectedValue = $value;
    });

    $this->assertTrue($sideEffectExecuted, 'inspect() should execute function on Ok');
    $this->assertEquals(42, $inspectedValue, 'inspect() should pass the value to the function');
    $this->assertSame($result, $returnedResult, 'inspect() should return the same instance');
}
```
