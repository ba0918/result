#### 2. src/Some.php
**変更内容**: flatten()メソッド実装
```php
/**
 * ネストしたOptionを一段階平坦化する
 *
 * @return Option<mixed>
 */
public function flatten(): Option
{
    return $this->value instanceof Option ? $this->value : $this;
}
```

**実装パターン**:
- Some(Option) → その内側のOption
- Some(非Option) → 自身を返す

/**

## 動作パターン

### 実装された動作ルール
1. **Some(Some(value))** → `Some(value)`
2. **Some(None)** → `None`
3. **Some(非Option値)** → `Some(非Option値)` (自身を返す)
4. **None** → `None` (自身を返す)

### 使用例
```php
// 基本的な平坦化
$nested = Some::of(Some::of(42));
$flattened = $nested->flatten(); // Some(42)

// None処理
$someNone = Some::of(None::instance());
$result = $someNone->flatten(); // None

// 非Option値
$nonOption = Some::of("value");
$unchanged = $nonOption->flatten(); // Some("value")

// 深いネスト（一段階のみ平坦化）
$deep = Some::of(Some::of(Some::of(42)));
$once = $deep->flatten(); // Some(Some(42))
$twice = $once->flatten(); // Some(42)
```

## 発見された課題と解決

### 1. PHPStanの型エラー
**問題**: テストコード内でmixed型演算エラー
```
Binary operation "*" between mixed and 2 results in an error.
```

**解決策**: 型アサーションを使用
```php
// 修正前
$mapped = $option->map(fn($x) => Some::of($x * 2));

// 修正後
$mapped = $option->map(function($x) {
    assert(is_int($x));
    return Some::of($x * 2);
});
```

### 2. アロー関数の構文制限
**問題**: アロー関数内での複数行処理が不可
**解決策**: function()キーワードの使用
