# or()/orElse()メソッド実装完了報告

**実装日時**: 2025-07-12 21:00:00  
**プロジェクト**: PHP Result型ライブラリ  
**実装機能**: or() / orElse() メソッド

## 実装概要

RustのResult型のor/or_elseメソッドをPHPに移植し、代替Resultを提供する機能を実装しました。

## 実装したファイル

### 1. 修正ファイル

#### src/Result.php
- or()とorElse()メソッドのシグネチャを追加
- 適切なPHPDocコメントとGenerics注釈を記述
- 型パラメータを柔軟に設計（`Result<T|U, F>`）

```php
/**
 * Errの場合に代替のResultを返す（即座評価）
 *
 * @template U
 * @template F
 * @param Result<U, F> $res
 * @return Result<T|U, F>
 */
public function or(Result $res): Result;

/**
 * Errの場合に代替のResultを返す（遅延評価）
 *
 * @template U
 * @template F
 * @param callable(E): Result<U, F> $fn
 * @return Result<T|U, F>
 */
public function orElse(callable $fn): Result;
```

#### src/Ok.php
- or()とorElse()メソッドを実装
- 両方とも自身（$this）を返すシンプルな実装

```php
#[\Override]
public function or(Result $res): Result
{
    return $this;
}

#[\Override]
public function orElse(callable $fn): Result
{
    return $this;
}
```

#### src/Err.php
- or()とorElse()メソッドを実装
- or()は引数のResultを返す（即座評価）
- orElse()はエラー値で関数を実行し結果を返す（遅延評価）

```php
#[\Override]
public function or(Result $res): Result
{
    return $res;
}

#[\Override]
public function orElse(callable $fn): Result
{
    return $fn($this->error);
}
```

## 新機能の使用方法

### 基本的な使用法

```php
// or(): 即座評価
$result = (new Err("エラー"))->or(new Ok("代替値"));
echo $result->unwrap(); // "代替値"

// orElse(): 遅延評価
$result = (new Err("エラー"))
    ->orElse(fn($error) => new Ok("処理済み: $error"));
echo $result->unwrap(); // "処理済み: エラー"
```

### 実用的なパターン

```php
// 複数の代替戦略
$result = fetchPrimaryData()
    ->or(fetchCacheData())
    ->orElse(fn($error) => createFallbackData($error));

// エラー回復チェーン
$result = new Err("主処理失敗")
    ->or(new Err("代替処理1も失敗"))
    ->or(new Err("代替処理2も失敗"))
    ->orElse(fn($error) => new Ok("最終代替値"));
```
