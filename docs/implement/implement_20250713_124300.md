## 実装詳細

### 1. OptionBasicTest.php修正
**対象エラー**: mixed型算術演算4件 + assertFalse最適化警告2件

#### 修正内容
1. **mixed型算術演算対応**:
   ```php
   // 修正前
   fn($x) => $x * 2
   
   // 修正後  
   function(mixed $x): int {
       assert(is_int($x));
       return $x * 2;
   }
   ```

2. **assertFalse最適化警告対応**:
   ```php
   // 修正前
   $this->assertFalse($option->contains(42));
   
   // 修正後
   // @phpstan-ignore method.impossibleType
   $this->assertFalse($option->contains(42));
   ```

3. **型不整合修正**:
   ```php
   // 修正前
   $this->assertSame(5, $result->unwrap());  // float値に対しint期待
   
   // 修正後
   $this->assertSame(5.0, $result->unwrap()); // 正しい型での期待値
   ```

### 2. OptionResultConversionTest.php修正
**対象エラー**: mixed型算術演算1件 + 文字列補間1件

#### 修正内容
```php
// mixed型算術演算
->map(function(mixed $x): int {
    assert(is_int($x));
    return $x * 2;
})

// 文字列補間エラー
->mapErr(function(mixed $e): string {
    assert(is_string($e));
    return "wrapped_{$e}";
})
```

### 3. TransposeTest.php修正
**対象エラー**: mixed型メソッド呼び出し26件

#### 修正内容
1. **useステートメント追加**:
   ```php
   use Mizumi\Result\Option;
   use Mizumi\Result\Result;
   ```

2. **PHPDocアノテーション使用**:
   ```php
   // transpose()戻り値の型明示
   /** @var Result<mixed,mixed> $result */
   $result = $optionResult->transpose();
   
   /** @var Option<mixed> $unwrapped */
   $unwrapped = $result->unwrap();
   ```

3. **複雑なメソッドチェーン対応**:
   ```php
   // 修正前
   Some::of(Ok::of(42))
       ->transpose()
       ->map(fn($opt) => $opt->map(fn($x) => $x * 2))
       ->unwrap()
       ->unwrap();

   // 修正後
   $transposed = Some::of(Ok::of(42))->transpose();
   $mapped = $transposed->map(function(mixed $opt) {
       /** @var Option<mixed> $opt */
       return $opt->map(function(mixed $x): int {
           assert(is_int($x));
           return $x * 2;
       });
   });
   ```

## 技術的アプローチ

### 1. 型安全性確保手法
- **型アサーション**: `assert(is_int($x))` による実行時型チェック
- **PHPDocアノテーション**: `/** @var Type $var */` による静的型情報提供
- **明示的型宣言**: `function(mixed $x): int` による引数・戻り値型明示

### 2. PHPStan対応策
- **@phpstan-ignore**: 既知の安全な警告のサプレッション
- **型キャスト回避**: mixed型の危険なキャストを避け、型チェック優先
- **ジェネリクス対応**: `Result<mixed,mixed>`, `Option<mixed>` による型推論支援

### 3. 品質維持戦略
- **テスト駆動**: 修正後に全テストスイート実行で機能確認
- **段階的修正**: ファイル単位での修正とエラー数確認
- **非破壊的変更**: 既存ロジックを変更せず型安全性のみ向上
