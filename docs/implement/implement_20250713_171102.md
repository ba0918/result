## 実装概要

前回のレビューで提案された4つの高度メソッドをRust互換で実装しました：

### Result型の新メソッド
1. **ok()** - 成功値をOption<T>として取得
2. **err()** - エラー値をOption<E>として取得
3. **expectErr()** - エラー値のカスタムメッセージ付き取り出し

### Option型の新メソッド
4. **xor()** - 排他的OR操作
5. **zip()** - 2つのOptionの結合

## 実装詳細

### Phase 1: Result型変換メソッド

#### 1. Result.phpインターフェース拡張
- `ok(): Option<T>` - 成功値のOption変換
- `err(): Option<E>` - エラー値のOption変換  
- `expectErr(string $message): E` - エラー値の取り出し

#### 2. Ok.php実装
```php
public function ok(): Option {
    /** @phpstan-ignore return.type */
    return Some::of($this->value);
}

public function err(): Option {
    return None::instance();
}

public function expectErr(string $message): mixed {
    throw new UnwrapException($message . ': ' . print_r($this->value, true));
}
```

#### 3. Err.php実装
```php
public function ok(): Option {
    return None::instance();
}

public function err(): Option {
    /** @phpstan-ignore return.type */
    return Some::of($this->error);
}

public function expectErr(string $message): mixed {
    return $this->error;
}
```

### Phase 2: Option型結合操作

#### 1. Option.phpインターフェース拡張
- `xor(Option $opt): Option<T|U>` - 排他的OR操作
- `zip(Option $opt): Option<array{T, U}>` - タプル結合

#### 2. Some.php実装
```php
public function xor(Option $opt): Option {
    return $opt->isNone() ? $this : None::instance();
}

public function zip(Option $opt): Option {
    /** @phpstan-ignore return.type,argument.type */
    return $opt->isSome() ? Some::of([$this->value, $opt->unwrap()]) : None::instance();
}
```

#### 3. None.php実装
```php
public function xor(Option $opt): Option {
    return $opt;
}

public function zip(Option $opt): Option {
    return $this;
}
```
