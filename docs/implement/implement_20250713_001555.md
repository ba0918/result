## 実装内容

### 新規追加メソッド

#### 1. `contains(mixed $value): bool`
- **機能:** Ok値が指定された値を含むかどうかを確認
- **比較方法:** 厳密比較（`===`）
- **戻り値:** Ok値が指定値と等価な場合`true`、それ以外は`false`

#### 2. `containsErr(mixed $error): bool`
- **機能:** Err値が指定されたエラーを含むかどうかを確認
- **比較方法:** 厳密比較（`===`）
- **戻り値:** Err値が指定エラーと等価な場合`true`、それ以外は`false`

## 技術仕様

### 比較動作
```php
// 厳密比較の例
$ok = new Ok(42);
$ok->contains(42);    // true
$ok->contains('42');  // false (型が異なる)
$ok->contains(42.0);  // false (型が異なる)

// null値の比較
$ok = new Ok(null);
$ok->contains(null);  // true
$ok->contains(0);     // false
$ok->contains('');    // false

// オブジェクト参照比較
$obj = new stdClass();
$ok = new Ok($obj);
$ok->contains($obj);           // true (同じ参照)
$ok->contains(new stdClass()); // false (異なる参照)

// 配列の厳密比較
$ok = new Ok([1, 2, 3]);
$ok->contains([1, 2, 3]);     // true
$ok->contains(['1', '2', '3']); // false (要素の型が異なる)
```

### 使用パターン
```php
// データ検証での使用
$result = processData();
if ($result->contains("expected_value")) {
    // 期待値と一致した場合の処理
}

// エラー処理での使用
$result = networkCall();
if ($result->containsErr("connection_timeout")) {
    // 特定のエラーに対する処理
}

// 条件分岐での使用
$response = apiCall();
match (true) {
    $response->contains("success") => handleSuccess(),
    $response->containsErr("rate_limit") => waitAndRetry(),
    $response->containsErr("auth_error") => refreshToken(),
    default => handleUnknownError()
};
```


```php
// 参照比較であることを理解して使用
```
